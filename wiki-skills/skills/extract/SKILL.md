# Explore a source

Read the topic's CLAUDE.md and wiki/README.md. Accept a URL, local artifact, code directory, pasted question or annotations. Reuse an artifact already in sources/. An external citation is sufficient for a public blog. Keep identifying details, internal examples, secrets and unsanitized private material out of the repository, including metadata and embedded diagram data.

Start from the user's question. Work through a concrete example, identify what the source claims, then discuss what the user concludes and what remains uncertain. Attribute suggestions and retrospective analysis separately. Ask focused questions only when they advance the learning goal; direct-ingest requests can go straight through update-wiki.

When saving a standalone synthesis, create or revise wiki/reading-notes/<topic>.md with the citation, main question, worked explanation, user observations and unresolved questions. Link it from the reading-notes catalog. For a narrow insight use update-wiki to incorporate it into an existing concept instead. A coding or design exercise can proceed directly to its problem page. Do not manufacture a separate extract for every input or attribute generated solutions to the user.
